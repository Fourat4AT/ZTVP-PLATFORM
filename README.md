# Internship Progress Repository

This private repository is used to track the **weekly progress and technical reports** of interns during their internship.

## Rules

- Each intern has a **dedicated branch**
- Work **only on your assigned branch**
- Do **not push to `main`**
- Write files **only inside your personal folder**

# Note

This repository is part of the official internship evaluation.
Incomplete, late, or missing updates may affect assessment.
